# 粒子登录页

Olares 登录页的替代实现。**界面本身就是粒子**，没有半透明卡片垫底：
用户名、提示、输入框边框、光标、箭头、密码点，全部是从「墨稿」栅格化出来的点阵；
头像仍是真实照片（DOM `<img>`），外面包一层三层环流。

```
auth/
├── index.html          一个 canvas + 一个透明 input + 头像 img
├── src/ui.js           墨稿（照官方登录页量的布局）+ 覆盖率采样
├── src/field.js        粒子场：骨架 / 云层 / 头像光晕
└── src/login.js        Authelia 协议（md5 加盐、X-Bfl-User、targetURL）
```

本地跑：

```bash
cd auth && python -m http.server 8811     # → http://127.0.0.1:8811/
```

`/bfl/info/v1/olares-info`、`/api/state` 取不到时自动降级（用户名回落 `owner`），
所以纯静态也能看效果，只有提交密码需要真实后端。

## 三层粒子

这套结构是照 `prototype/src/main.js` 的物理搬过来的，不是重新设计的。

| 层 | 数量 | 行为 |
| --- | --- | --- |
| **骨架 skeleton** | ~1300（按墨稿格数） | 点阵本体。弹簧跟随槽位，**不是钉死**：整片被一个相干 fbm 流场推着缓慢起伏（±2px / 5s），弹簧略欠阻尼，所以一直有回弹 |
| **云层 cloud** | 2400 | 指针在时围着指针公转（半径 16–62px，逐粒子随机相位/角速度 → 剪切流动）；压到控件上时按「离控件中心由近及远」倾泻进该控件的**细网格槽位**，控件被灌满 → 变亮变密 = "更清楚"；挤不进去的其余粒子把半径外扩成光晕。指针离开 → 沉成 190–470px 的缓慢星尘 |
| **头像光晕** | 1100 | 贴身 / 中层 / 外雾三层环流，角速度内快外慢，亮度带沿圆周扫过（顶点着色器算，便宜） |

三个必须记住的结论（都是踩过的坑）：

1. **流场必须相干**。逐粒子 `sin(t + seed)` 做位移 = 噪点闪烁；按屏幕坐标采样 fbm，
   邻域受力一致，整片才像"形在呼吸"。为省算力，fbm 在 36×26 的粗网格上算一遍，
   粒子做双线性采样——视觉等价，便宜两个数量级。
2. **弹簧不能有死区**。曾经写成「距目标 < 0.15px 就吸附归零」，结果每颗粒子都钉死在
   格心，整页看起来像一张贴图。只要去掉吸附，同样的目标点立刻"活"了。
3. **聚合要有下限**。槽位粒子的微旋半径 0.9px（不是 0，否则死板；也不是 5px，否则糊）。

## 字体工程

点阵字能不能读，取决于**笔画占多少格**，跟字号关系没那么大。原型 v0.14 做过量化
（`.tmp/fontprobe.html` 用生产同款采样算法把候选字体点阵化）：

| 字体 | 笔画 ÷ 点距 | 结果 |
| --- | --- | --- |
| 微软雅黑 400 / SimHei | 1.2 格，4 邻域连通度 2.6–3.0 | 每个笔画横截面占 2 格，字怀被填死 → 糊成块 |
| **等线 Light (DengXian Light)** | 0.8 格，连通度 2.1–2.3 | 笔画恰 1 格、字怀留 1 格暗缝 → 能认 |

所以：

- 中文 `"DengXian Light" → "Microsoft YaHei Light" → "PingFang SC"`，字重 **300**
- 西文 `Bahnschrift Light → Bahnschrift`，字重 **400**（Light 在 30px 时笔画只有
  0.6 格，点阵会碎成散点；400 才够 0.84 格）
- 汉字之间加 **一格字距**：全角字默认紧贴，两个字会并成一团；居中时要补偿 `-track/2`
  （Chrome 把尾随字距算进宽度）
- 文字**不加描边**：加宽笔画等于把字怀填死，这是"糊"的另一半原因
- 点阵格 `CELL = 1.9`：32–35px 的等线 Light 笔画 ≈1.6px = 0.84 格，恰好"一笔一格"。
  格子上到 2.2 时同一行字只有 0.7 格，笔画随机断点 → 碎
- 点径 `1.45 × CELL`：硬芯圆点（`1 - smoothstep(0.82, 1.0, r)`），直径略大于点距，
  相邻点相切连成笔画；`1.12` 会看起来是一地散珠，`1.55` 就糊成实心块

## 交互

- 悬停某个控件 → 云层倾泻进它，同时骨架里属于该控件的点`aHot` 提亮 55%、加粗 10%
- 点击 → 从触点推一圈冲击波（骨架只吃 22%，文字不跟着晃）
- 提交成功 → 点阵与头像环流一起炸开，760ms 后跳 targetURL

输入法靠一个透明 `<input>` 收键盘，它的位置/宽度由墨稿实测出来的 `HIT.input` 反推，
右侧让出 34px 给箭头，否则箭头被 input 盖住点不到。

## 认证协议（照抄官方，不能改）

```
GET  /bfl/info/v1/olares-info   → { data: { olaresId, osVersion, avatar } }
GET  /api/state                 → authentication_level === 2 表示已登录
POST /api/firstfactor           → { username, password, keepMeLoggedIn, targetURL }
```

- `osVersion >= 1.12.0` 时 password 要变成 `md5(password + "@Olares2025")`
- 网关认不出用户时报 `Cannot get user name from header` → 带 `X-Bfl-User` 重试一次
- `targetURL` 默认 `https://desktop.<olaresId 的 @ 换成 .>`，有 `?rd=` / `?redirect=` 时以它为准

官方前端注册过 `scope=/` 的 Service Worker，会一直喂旧缓存，所以 `index.html` 里先注销一次；
首次访问仍可能命中旧 SW，需要手动 Clear site data。
